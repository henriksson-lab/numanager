# Documentation Map

This directory is organized by document purpose.

| Area | Purpose |
| --- | --- |
| [`devices/`](devices/README.md) | Per-driver device pages, support matrix, and hardware-validation template |
| [`reverse/`](reverse/README.md) | Protocol-evidence notes, blocked target gates, and trace-capture workflow |
| [`inventory/`](inventory/README.md) | Broad adapter/manufacturer protocol inventories |
| [`reference/`](reference/README.md) | Domain reference notes used by implementation, such as spectra and rendering data |
| [`planning/`](planning/README.md) | Roadmaps and implementation planning |
| [`core_model.md`](core_model.md) | Runtime graph, typed values, capabilities, and API vocabulary |
| [`run_examples.md`](run_examples.md) | Public example commands and GUI launch commands |
| [`example_outputs.md`](example_outputs.md) | Recorded public example output used by audits |
| [`protocol_evidence_plan.md`](protocol_evidence_plan.md) | Clean-room evidence policy for protocol specifications |
